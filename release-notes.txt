Echo 0.1.10 refreshes the interface and simplifies local Ultra setup.
- Compact, content-first layout with icon navigation, a single selectable transcript textbox, Arial text, and a 100-line transcript display. Older saved history is retained.
- Activity, settings, dialogs, and the live overlay have been refined. The recording indicator uses an animated waveform in the app and tray while dictating.
- Parakeet Ultra now installs pinned, hash-verified Python and GPU dependencies directly from upstream sources. A prebuilt runtime bundle is no longer required.
- Starting Ultra before its model is ready shows a loading notice and does not start a recording session. Press the shortcut again once the model is ready.
- CPU speech models and existing settings remain supported.
